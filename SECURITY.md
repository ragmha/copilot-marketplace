# Security Policy

## Reporting a vulnerability

For vulnerabilities in this marketplace site or repository code, please report them through GitHub Private Vulnerability Reporting for this repository if it is available in your environment. If Private Vulnerability Reporting is unavailable, open a minimal issue without exploit details or contact the repository owner through GitHub to arrange a private disclosure channel.

Please do not include exploit details in public issues, pull requests, or discussions.

## Scope

This policy applies to the marketplace repository itself, its site, workflows, and generated config. Vulnerabilities in a plugin listed by this catalog belong in that plugin's own upstream repository, not in this repository.

## Supported versions

This repository is a template and is primarily maintained on the default branch. The supported version is the default branch; if releases are published, only the current release is supported. Older forks, branches, and unpublished copies are not individually supported, and there is no guaranteed SLA for disclosure handling.
